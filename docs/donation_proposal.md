## 一句话介绍

**MatWAU 是一个"材料科学 AI 实验室小工坊",由校友团队 XploreAlpha 捐赠给母校,Apache 2.0 开源,完全部署在学校服务器,本校师生可永久免费使用。**

---

## 一、能给学院带来什么?(3 件)

| 维度 | 价值 | 落地路径 |
|---|---|---|
| 🎓 **教学** | 一套完整的"AI 决策 + 机器人执行 + 仪器测试"实验课 | 8 周本科生选修课 / 研究生方法课 |
| 🔬 **科研** | 30+ 开箱即用的材料 agent,覆盖金属 / 聚合物 / 陶瓷 3 大材料域 | 各课题组直接调用,做先导实验 |
| 🏛️ **示范** | 学院可对外展示"AI + 自动化实验室"的样板工程 | 对外接待 / 学科评估 / 招生宣传 |

---

## 二、是什么?不是什么?(避免误会)

### ✅ 是

- 一套**可装可跑**的 Python 工具集(35 周研发完成,**1298 个测试通过**)
- 17 个 agent(造物主 / 试菜员 / 超算员 / 实验老师 / 翻译官 / 裁决者 / 主动学习 / 成本 / 血缘 / 化学师 / 4 个机器人 / 域路由)
- 覆盖 3 大材料域(金属合金 / 聚合物 / 陶瓷)
- Stage 3 JARVIS 雏形(从"会跑"到"可观测"到"可解释")
- Mock SDK 完整(无真仪器也能跑完整流程)

### ❌ 不是

- ❌ 不是商业化产品(无任何付费 / 订阅 / 广告)
- ❌ 不是云服务(完全装在学校服务器,**不上传任何数据**)
- ❌ 不是替代导师 / 学生的工具(是辅助,不是替代)
- ❌ 不是"开箱即得诺贝尔奖"的承诺(是工程基础,需要师生继续耕耘)
- ❌ 不绑定单一硬件厂商(SDK 可换)

## 三、对学院有什么要求?(极简)

| 项 | 要求 |
|---|---|
| **服务器** | 1 台 8C16G Linux VM(最低配置);学院已有同等或更强配置即可 |
| **存储** | 100 GB(数据血缘 + 文献缓存 + 模型缓存)|
| **网络** | 可选外网(如要启用 LLM 复核);断网完全可用(走 mock)|
| **IT 人力** | 0.1 FTE(部署 + 升级 + 偶尔答疑);XploreAlpha 提供文档 + 远程支持 |
| **学院 IT 安全** | Apache 2.0 允许内部审计;代码完全公开,可学院内 fork |

**简单说**:服务器给一台,IT 给半天,其它我们全包。
