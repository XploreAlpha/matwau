## 一句话定位

**v2.0 = "WAU 网络 OS + App 生态 + Siri 入口"的学院版成形**

```mermaid
flowchart TB
    subgraph cloud["☁️ 云端 WAU 网络 OS(不存数据)"]
        kernel["wau-core-kernel<br/>(中央调度 / 路由 / 信任)"]
        registry["wau-registry<br/>(App 目录 — 类 App Store)"]
        trust["wau-trust<br/>(信任链 — 类 iCloud)"]
        kernel --> registry
        kernel --> trust
    end

    subgraph onprem["🏛️ 🏢 各类本机(数据归属本机所有者)"]
        matwau["MatWAU<br/>(学院本机)"]
        corp["企业 agent<br/>(企业本机)"]
        other["其他学院 agent<br/>(学院本机)"]
    end

    homerail["🎙️ HomeRail<br/>(个人本机 — 类 Siri)"]
    user["👤 用户<br/>(iPhone / iPad / 任何设备)"]

    kernel <-->|"WAU 协议"| matwau
    kernel <-->|"WAU 协议"| corp
    kernel <-->|"WAU 协议"| other

    matwau -.->|"WauWorkflow 协议"| homerail
    corp -.->|"WauWorkflow 协议"| homerail
    other -.->|"WauWorkflow 协议"| homerail

    homerail --> user

    style cloud fill:#e3f2fd,stroke:#1565c0
    style kernel fill:#fff3e0,stroke:#e65100
    style onprem fill:#c8e6c9,stroke:#1b5e20
    style homerail fill:#fff9c4,stroke:#f57f17
    style user fill:#fce4ec,stroke:#c62828
```

**类比 Apple**:
- **wau-core-kernel** = iOS
- **MatWAU / 企业 / 学院 agent** = 各种 App
- **HomeRail** = Siri
- **每个本机** = iPhone / iPad

---

## 三方角色(清晰边界)

| 角色 | 部署位置 | 数据归属 |
|---|---|---|
| **wau-core-kernel** | ☁️ 云端 | 公开(只调度)|
| **MatWAU / 企业 / 其他学院 agent** | 🏛️ 🏢 本机 | **本机所有者** |
| **HomeRail** | 🏠 个人本机 | **个人** |

**核心原则**: 云端不存数据,各本机数据不出本机,跨域协作通过协议。

## 与 v1.x 的本质变化

| 维度 | v1.x | v2.0 |
|---|---|---|
| 范围 | 单本机自给自足 | 多本机协同 |
| 学院 | 1 所 | 多所 |
| 用户 | 学院 / 个人 | 学院 / 企业 / 个人 |
| 定位 | **工具** | **生态** |
